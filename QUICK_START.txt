⚠️  IMPORTANT: Don't open index.html directly in browser!

The file:// protocol blocks fetch requests for security reasons.
You MUST use a local HTTP server.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ SIMPLEST METHOD: Python Server

1. Open Command Prompt or PowerShell
2. Navigate to the project folder:
   
   cd "p:\book store"

3. Start the server:
   
   python -m http.server 8000

4. Open your browser and go to:
   
   http://localhost:8000

5. You're done! App loads automatically

🎯 TROUBLESHOOTING

Q: "Error loading page" message shows
A: You're not using a local server. Follow the Python method above.

Q: "python command not found"
A: Install Python from https://www.python.org
   Make sure to check "Add Python to PATH" during installation

Q: Port 8000 already in use
A: Use a different port:
   python -m http.server 8001
   Then open http://localhost:8001

Q: Want to use VS Code instead?
A: 1. Install "Live Server" extension
   2. Right-click index.html
   3. Click "Open with Live Server"
   4. Browser opens automatically
